## PHP Webshop eindproject

Dit is mijn eindproject voor de Bit Academy. Ik heb een webshop gebouwd in PHP met een databasekoppeling.

## Pagina's en structuur

Homepagina:
Overzicht van alle producten uit de database.

Productpagina:
Details bekijken van een specifiek product.

Winkelwagentje:
Producten toevoegen, bekijken en het overzicht bijhouden.

Inlogpagina:
Inlogsysteem voor mensen om een account aan te maken en in te loggen.

Logoutpagina:
Uitlogsysteem voor uitloggen.

Gastlogin:
Inloggen als een gast zonder dat je een account toevoegt

## Belangrijke functionaliteiten

Databasekoppeling:
Alle producten en categorieën worden direct uit de database geladen.

Winkelmand functionaliteit:
Met de winkelwagenknop kan je producten opslaan. Bij het afrekenen berekent de backend de totale prijs.

Gebruikersbeheer (Backend):
Controleren of het inloggen en registreren van accounts veilig en goed werkt in de database.

W3C Validatie:
Alle HTML en CSS code is gecontroleerd en volledig geldig volgens de W3C richtlijnen.
